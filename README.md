
This project is a **Python-based Reminder Application** designed to notify users about scheduled tasks at specific times.  
The application helps users manage daily activities such as checking GitHub repositories, attending meetings, or completing assignments by sending time-based notifications.

---

## 📌 Project Description

The Reminder Application allows users to define tasks along with a specific time.  
Once the scheduled time is reached, the system triggers a notification and logs the reminder activity for tracking purposes.

This project demonstrates the use of **task scheduling, system notifications, logging, and object-oriented programming** concepts in Python.

---

## 🎯 Project Objectives

- Practice Python programming and clean code structure
- Work with time-based scheduling
- Implement system notifications
- Apply logging for debugging and monitoring
- Develop a practical utility suitable for academic evaluation

---

## ✨ Features

- ⏰ **Scheduled Reminders**
  - Set reminders for specific times of the day
  - Example: *Remind me at 14:00 to check my GitHub account*

- 🔔 **Desktop Notifications**
  - Uses system notifications to alert the user
  - Notification title and message are customizable

- 🗂 **Logging System**
  - Reminder activities are stored in a rotating log file
  - Logs are also displayed in the console

- 🧠 **Modular Design**
  - Uses classes and data structures for reminder handling
  - Easily extendable for future features



⚠️ Limitations
The application must remain running to trigger reminders
No database is used; reminders are not persisted after closing the program
Designed for single-user, local usage
